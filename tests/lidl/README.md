The API of lidl is basically unusable because of the horrendous search results that you get. 
It is insane how bad the search engine is of lidl, some products don't even show up, or they get mixed with a lot of random products that don't have anything to do with it.
(i.e. green beans show up when looking up apples, I searched for "Yoghurt" before and no yoghurt turned up in the search results, I did get nectarines and furniture though...)

Therefore we will not use the Lidl API in the final product, I also looked at just fetching the product information using webscraping with selenium, but the search results are basically the same on their actual webpage, so I don't know how I would correctly find the right products there either.
I'm not looking to build a whole new search engine for all these products, so therefore I will leave this as is, maybe at a later stage when we are capable of holding the entire lidl assortment in our database we can categorize them correctly and query on that, but for now it won't get an implementation.
